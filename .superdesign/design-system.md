# Medora Design System

Medora is a hospital administration platform with a calm, clinical green visual language. Use the existing tokens in `.superdesign/init/theme.md`: deep green #015b2d, primary #168447, soft green #62b947, pale mint background #f5faf7, white surfaces, green-tinted borders and shadows. Use Inter/Manrope, compact admin density, 8–12px controls, 18px cards, expandable left sidebar, crisp table hierarchy, and accessible status badges.
